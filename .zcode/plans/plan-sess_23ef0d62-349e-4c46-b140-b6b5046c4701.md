## 全局替换为 LockScreen 液态玻璃配方 + 设置页调控

### LockScreen 配方（来自 kyant catalog `LockScreenContent.kt`）
`drawPlainBackdrop` + `colorControls(亮度/对比度/饱和度)` + `blur()` + 在 backdrop 上叠半透明白（`onDrawBackdrop { drawBackdrop(); drawRect(White) }`），无 highlight/无 shadow/无 lens。`colorControls` 是 ColorMatrix 滤镜（`vibrancy()` 就是它 saturation=1.5 的特例）。

### 修改文件（4 个）

**1. 新增 `core/GlassStyleStore.kt`**（仿 ThemeStore 模式）
- `data class GlassStyle(brightness=-0.10f, contrast=0.75f, saturation=1.5f, whiteOverlay=0.25f, blurCardDp=8f)`，默认值取自 LockScreen（blur 适度上调保证卡片可读，可用滑杆调回 2dp）
- object 内含 Compose `mutableStateOf` 快照态 + SharedPreferences("vibe_usage") 持久化，`init(context)` / `set(context, style)`；所有 composable 直接读快照态 → 改动全局实时生效

**2. 重写 `ui/glass/GlassSurfaces.kt` 三个函数**
- `glassCard` / `glassRow` / `glassTile` 全部改为 LockScreen 配方（drawPlainBackdrop + colorControls + blur + 白色叠加）
- 行/磁贴模糊 = 卡片模糊 × 0.7 / × 0.5（小元素降模糊）
- 移除 Shadow / Highlight / lens / Surface 色填充（LockScreen 无这些）；保留 `tint` 参数兼容（有值时替代白色叠加），32 处调用点签名不变

**3. `ui/SettingsScreen.kt` 新增"液态玻璃"设置卡**（外观分组内、背景卡之后）
- 5 个滑杆：亮度(-0.5~0.5)、对比度(0.5~1.5)、饱和度(0~2)、模糊(0~32dp)、白色叠加(0~0.5)，右侧显示当前值
- "恢复默认"行；新增 `Icons.Filled.Tune` 图标 + M3 Slider（项目目前没用过 Slider，extended icons 已在 classpath）

**4. `MainActivity.kt`**：AppRoot 里一行 `GlassStyleStore.init(context)`

### 不动
- `LiquidBottomTabs` / `LiquidGlassSegmentedControl`：交互型 catalog 组件，按压 lens 动效依赖原配方，不改（静止态观感由全局 colorControls 风格统一衬托）
- `GlassBackground.kt`、`GlassTokens.kt` 调色板、kyant 库
