VibeUsage 液态玻璃

基于 Jetpack Compose 的 Token 用量统计客户端 · 为 vibecafe.ai 打造

《VibeUsage——液态玻璃风格 Token 用量客户端》作品描述

VibeUsage 是一款为 vibecafe.ai 打造的 Android Token 用量统计客户端，以液态玻璃美学为设计核心，让数据可视化兼具通透与精致。应用基于 Jetpack Compose 与 Kyant0 backdrop 引擎，借助 GPU RuntimeShader 实现真实折射、模糊与高光，玻璃卡片、分段滑块与设置菜单在光影中流动，界面既具科技感又有艺术质感。

功能上，应用提供总消耗、趋势、应用分布与模型消耗等核心指标，支持今日、24 小时、7 天、30 天、全部五种时间范围切换；每个工具与模型自动匹配官方彩色品牌标识（Claude、OpenAI、Gemini、DeepSeek、Qwen、Kimi 等），并以模糊匹配保证新增模型也能正确识别。用户还可自定义背景图片，内置思源黑体，中英文排版统一清晰。

工程上，应用仅申请网络权限，API Key 只保存在本地，隐私安全；统计引擎独立封装，代码结构清晰，模拟器与真机渲染一致。VibeUsage 不止是工具，更是"让数据拥有质感"的设计实践。
